# Contributing

Contributions that improve reliability, add tests, add documentation, or expand aircraft/hardware support are welcome.

Before submitting a pull request:

1. Keep aircraft-specific assumptions isolated where practical.
2. Do not include proprietary aircraft files, copied vendor code, assets, credentials, or other material you do not have permission to redistribute.
3. Add or update tests for behavior that can be tested independently of Microsoft Flight Simulator.
4. Describe the simulator, aircraft version/build, hardware and MobiFlight version used for testing.
5. Keep changes focused so they can be reviewed independently.

By submitting a contribution, you agree that your contribution may be distributed under the repository's current license terms.
